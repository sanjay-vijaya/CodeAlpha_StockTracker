# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## 🚀 Features

- View available stocks
- Display stock symbol, price, and volume
- Search for stocks by name
- Enter stock quantity
- Calculate total investment amount
- Validate stock availability
- Save portfolio details as a CSV file

## 🛠️ Technologies Used

- Python
- CSV Module

## 💻 How It Works

1. The program displays available stocks.
2. The user enters a stock name.
3. The program checks whether the stock is available.
4. The user enters the quantity of shares.
5. The total investment amount is calculated.
6. The portfolio details are displayed.
7. The user can optionally save the result as a CSV file.
